# NamaHCLAuto
Auto-skip days to farm materials in Reclamation Algorithm.
Theoretically supports both CN and JP servers at present.
Comes with two built-in configuration files:
- The default `config.json`: Automatically skips days to farm materials. Every 3 skipped days, it will automatically visit the store to purchase Fresh Water and Clearstone.
- `daysonly.json`: Only skips days to farm materials.

If you need to perform other operations, you can modify the config manually.
